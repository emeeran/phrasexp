# Project Context: Spec-Driven Development (SDD)

## Tech Stack
- **Backend:** Python (FastAPI) managed via `uv`
- **OS:** Ubuntu 24.x
- **Workflow:** Vibe Coding / Spec-Driven Development

## Pipeline
1. Domain -> 2. Requirements -> 3. Spec -> 4. ADR -> 5. Review (PASS required) -> 6. Code

## Commands
- Use `uv run` to execute scripts.
- Always check `backend/.venv` for the environment.
- Follow `prompts/` templates strictly.
